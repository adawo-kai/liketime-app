# LikeTime

Система учёта посещаемости учеников и расчёта зарплаты преподавателей.

Будущая интеграция: распознавание лиц на устройстве Dahua DHI-ASI3213A-W.

## Стек

- **Backend:** Java 21, Spring Boot 3.5.16, Spring Security (JWT), Spring Data JPA / Hibernate, Flyway
- **База данных:** MySQL 8.0
- **Frontend:** React, TypeScript, Vite (пока не начат)
- **Сборка backend:** Maven (через Maven Wrapper)

## Что уже сделано

### Этап 1. Каркас
- Spring Boot 3.5.16 проект, Maven Wrapper.
- Профили `dev` (база `liketime_dev`) и `test` (база `liketime_test`).
- Часовой пояс: все даты хранятся в UTC. Схема ведётся только через Flyway, Hibernate лишь проверяет соответствие сущностей (`ddl-auto: validate`).

### Этап 2. Справочники
Миграция `V1__reference_data.sql`:
- `users`: пользователи с ролями `ADMIN`, `MANAGER`, `TEACHER`.
- `teachers`, `students`: статусы `ACTIVE` / `INACTIVE`, удаление мягкое.
- `subjects`, `rooms`: справочники.
- `devices`: устройства распознавания. В базе хранится только ссылка на секрет, не сам секрет.

Ограничения: уникальные логины, уникальные серийные номера устройств, связь преподавателя с пользователем один к одному, CHECK-ограничения на статусы и роли.

### Этап 3. Авторизация и роли
- `POST /api/auth/login`: вход по логину и паролю, в ответ Bearer-токен (8 часов).
- `GET /api/auth/me`: текущий пользователь и его роль.
- Управление пользователями (только `ADMIN`): `GET /api/users`, `POST /api/users`, `PATCH /api/users/{id}` (роль, активность), `PUT /api/users/{id}/password`.
- Роль и активность проверяются в базе при каждом запросе, поэтому отключение пользователя действует сразу.
- Администратор не может отключить или понизить себя, и в системе всегда остаётся хотя бы один активный администратор.
- Пароли хранятся в виде BCrypt-хеша.
- Первый администратор создаётся при старте, если в базе нет пользователей. Логин и пароль задаются в `application-local.properties`.

## Запуск (dev)

Нужны: JDK 21, MySQL 8.0, Git.

1. Создайте базу и пользователя MySQL (команды подготовлены отдельно, в репозитории их нет). Базы: `liketime_dev`, `liketime_test`. Права пользователю выдайте только на эти базы.
2. Создайте файл `backend/src/main/resources/application-local.properties` со строками:
   ```properties
   spring.datasource.username=<пользователь БД>
   spring.datasource.password=<пароль БД>
   liketime.security.jwt-secret=<случайная строка не короче 32 символов>
   liketime.bootstrap.admin.login=admin
   liketime.bootstrap.admin.password=<пароль первого администратора, не короче 10 символов>
   ```
   Файл игнорируется git и не должен попадать в репозиторий.
3. Запустите приложение:
   ```bash
   cd backend
   ./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
   ```
4. Войдите:
   ```bash
   curl -X POST http://localhost:8080/api/auth/login -H "Content-Type: application/json" -d '{"login":"admin","password":"<пароль>"}'
   ```

Пароль первого администратора задаётся один раз, при создании. Изменить его позже можно через `PUT /api/users/{id}/password`.

## Безопасность

- Секреты (пароли БД, JWT-секрет, пароль администратора) не хранятся в репозитории.
- `application-local.properties`, `.env` и `*.local` в `.gitignore`.
- Ограничения на попытки входа пока нет, его добавим до выхода в эксплуатацию.
