# LikeTime

Система учёта посещаемости учеников и расчёта зарплаты преподавателей.

Будущая интеграция: распознавание лиц на устройстве Dahua DHI-ASI3213A-W.

## Стек

- **Backend:** Java 21, Spring Boot 3.5.16, Spring Security (JWT), Spring Data JPA / Hibernate, Flyway
- **База данных:** MySQL 8.0
- **Frontend:** React, TypeScript, Vite
- **Сборка backend:** Maven (через Maven Wrapper)

## Что уже сделано

### Этап 1. Каркас
- Spring Boot 3.5.16 проект, Maven Wrapper.
- Профили `dev` (база `liketime_dev`) и `test` (база `liketime_test`).
- Часовой пояс: все даты хранятся в UTC. Схема ведётся только через Flyway, Hibernate лишь проверяет соответствие сущностей (`ddl-auto: validate`).

### Этап 2. Справочники
Миграция `V1__reference_data.sql`:
- `users`: пользователи с ролями `ADMIN`, `MANAGER`, `TEACHER`.
- `teachers`, `students`: статусы `ACTIVE` / `INACTIVE`, удаление мягкое.
- `subjects`, `rooms`: справочники.
- `devices`: устройства распознавания. В базе хранится только ссылка на секрет, не сам секрет.

Ограничения: уникальные логины, уникальные серийные номера устройств, связь преподавателя с пользователем один к одному, CHECK-ограничения на статусы и роли.

### Этап 4. Ученики, преподаватели, группы
Миграция `V2__students_teachers_groups.sql`: таблицы `study_groups` и `group_students` (состав группы с историей: `joined_on` / `left_on`, ученик не может состоять в группе дважды одновременно).

API (доступ ADMIN и MANAGER, если не указано иное):
- `/api/students`: список (`?status=`, `?q=` поиск по имени), карточка, создание, изменение, `DELETE` (мягкое удаление, ученик выходит из всех групп), `PUT /{id}/activate`.
- `/api/teachers`: то же самое; можно привязать учётную запись с ролью TEACHER (одну на преподавателя). Преподавателя с активными группами отключить нельзя.
- `/api/groups`: список, карточка, создание, изменение, `DELETE` (архивация), `PUT /{id}/restore`. Чтение доступно и роли TEACHER, но только для своих групп.
- `/api/groups/{id}/students`: состав (`?activeOnly=false` покажет и историю), `POST` добавить (`studentId`, необязательная `joinedOn`), `DELETE /{studentId}` убрать из группы.

## Сайт (frontend)

React + TypeScript + Vite, папка `frontend/`. Вход по логину и паролю, меню зависит от роли:
- **ADMIN**: группы, ученики, преподаватели, пользователи (создание, роли, отключение, сброс пароля).
- **MANAGER**: группы, ученики, преподаватели.
- **TEACHER**: «Мои группы» (только чтение, только свои группы).

Запуск (backend должен работать на порту 8080):

```bash
cd frontend
npm install
npm run dev
```

Сайт откроется на http://localhost:5173. Запросы `/api` проксируются на backend (см. `vite.config.ts`).
Продакшн-сборка: `npm run build`.

## Безопасность

- Секреты (пароли БД, JWT-секрет, пароль администратора) не хранятся в репозитории.
- `application-local.properties`, `.env` и `*.local` в `.gitignore`.
- Ограничения на попытки входа пока нет, его добавим до выхода в эксплуатацию.
